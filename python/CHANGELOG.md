# Changelog

All notable changes to the `orgdatacore` Python package are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
While on `0.x` the public API is not yet stable: breaking changes bump the **minor**
version (`0.1.0` → `0.2.0` → …) until the API is frozen at `1.0.0`.

## [0.1.0] - 2026-11-18

Initial release of the `orgdatacore` Python package on the `0.x` line — O(1)
organizational data lookups (employees, teams, orgs, pillars, team groups) over
pre-computed indexes, with sync and async services and an optional GCS data source.
